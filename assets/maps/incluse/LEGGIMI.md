# Mappe base

Le mappe di questa cartella vengono con l'app (spec 030, D-045): chi apre
l'app per la prima volta le trova già pronte, nel gruppo «Mappe base» di
Mappe, «Nuova partita» e «＋ Nuova puntata», in fondo, dopo le mappe del
browser (spec 033).

Oggi sono le tre mappe di default (spec 036, D-056): Pianeta Nameck,
Pianeta dei Kaioshin e Inferi, fatte con le regole delle mappe (D-051) e
con le partenze in due angoli opposti.

Per aggiungerne una:

1. nell'editor delle mappe, apri la mappa e premi «Esporta file»;
2. copia il file `.json` scaricato in questa cartella (il nome del file
   non conta: nel menu compare il nome scritto nella mappa);
3. riavvia l'app con il launcher.

- Le mappe base si usano così come sono: per modificarne una, in Mappe
  premi «Copia nelle mie mappe».
- Ogni file contiene anche lo sfondo, quindi pesa qualche MB: l'app lo
  legge solo quando servono le mappe, non all'avvio.
- Cambiare o togliere un file qui non tocca le mappe e le puntate già
  salvate nel browser.
