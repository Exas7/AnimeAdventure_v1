# Assets

Le immagini del progetto, divise per tipo (D-021, spec 011).

| Cartella | Cosa contiene | Usata dall'app |
| --- | --- | --- |
| `maps/` | Sfondi delle mappe | Sì: menu "Sfondi…" dell'editor delle mappe |
| `characters/` | Immagini dei personaggi | Sì: nelle caselle e nelle schermate, abbinate dal nome del file (vedi la nota nella cartella) |
| `layout/` | Cornici, loghi, grafica dello stream | Non ancora |
| `items/` | Immagini degli oggetti del negozio | Sì: nel negozio e nell'inventario, abbinate dal nome del file; git non le salva (vedi la nota nella cartella) |

- Formati: JPG, PNG o WebP.
- Un'immagine nuova compare nell'app al prossimo avvio col doppio clic su
  `Avvia Anime Adventure.bat`.
- Nei nomi dei file usa il trattino basso al posto degli spazi
  (`Pianeta_Nameck.jpg`): nell'app diventa "Pianeta Nameck".
